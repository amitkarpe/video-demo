# Environment

Status: PARTIAL

This milestone uses a local Apple Silicon Mac with native macOS speech (`say`), Apple Swift/AppKit for scene rendering, Python 3 for orchestration, and FFmpeg for media encoding. FFmpeg is free and may be installed with Homebrew under the user's explicit instruction. No cloud identity or AWS access is required. See `demo/README.md` for exact commands and verification results. The specific Mac tool versions are observed at execution time; this is not a general cloud-development readiness claim.
