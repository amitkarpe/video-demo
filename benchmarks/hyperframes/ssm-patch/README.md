# Patching Running Servers in AWS Factory — Scanned Is Not Patched

A public explainer of about 2.5 minutes for engineers and managers (Issue #35): how AWS Factory keeps running servers patched with AWS Systems Manager Patch Manager. The look is a **3D miniature world built with Three.js** and rendered by HyperFrames through its native `hf-seek` runtime.

**Status: Phase 1.** The review pack is in `phase1/`. Phase 2, the full film, starts after the owner's approval.
