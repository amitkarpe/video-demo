## Scope and constraints

- Produce five readable scenes, prominently labeled **SIMULATION / MOCK**, at 720p minimum, preferably 1080p.
- Use free tools already available; ask before installing software or granting Mac security permissions. No paid tools, subscriptions, API keys, or external speech services.
- No live AWS calls, credentials, real incident data, infrastructure, security changes, or automatic deployment.
- Keep an editable storyboard and script, captions, and minimal repeatable generation instructions in the repository. Keep the MP4 locally unless it is small and appropriate for Git.
- Deliver one cohesive PR with the sources, an MP4 path or link, and honest verification evidence. Do not merge without separate authority.

## Success evidence

A complete MP4 plays with English synthesized narration and readable captions, represents all five steps, and shows the mock label. Make one wording revision and successfully re-export without paid credits or watermark. Record the method, checks, limitations, and retained artifacts.
