# Voxel Kingdom — Three.js flythrough (interactive demo)

One self-contained HTML file: a procedural voxel world (castle, village, windmill, lighthouse, harbour, waterfalls, floating islands, day and night) with a looping spline camera and touch controls, built for iPhone Safari. No images, models or API keys. It loads a pinned Three.js from jsDelivr. Originally PR #37; physical iPhone check still pending.

This is the "castle at night" experiment: a **new theme**, built from scratch. It shows why the house rule is reuse first. Open `index.html` through any static web server.
