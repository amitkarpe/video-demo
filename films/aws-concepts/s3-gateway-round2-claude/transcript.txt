This EC2 instance has no public IP. No NAT. No internet gateway. Yet it still reads from Amazon S3. So what's the path? DNS first: the bucket name resolves to Amazon S3's public IP addresses. Then the route table decides. One route does it. Destination: the AWS-managed S3 prefix list for this Region. Target: the gateway endpoint. Matching traffic takes that route and stays on the AWS network. It's not an interface endpoint: no network interface, no private IP. Not a NAT either. Just a route target. But a route is not a permission. Security groups and network ACLs must still allow the traffic. IAM, the endpoint policy and the bucket policy still decide access. The route changed. The permissions didn't disappear.
