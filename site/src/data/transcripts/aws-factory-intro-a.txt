Every server we run starts as a copy of an image.
So when something must change, the best fix is to change the image, once.
AWS Factory starts with one approved upstream image.
It adds the latest patches, agent software that stays switched off, and selected security controls. The result is one hardened base.
From that base, it builds three families: GitLab, MongoDB, and the CloudOS workspace on ECS.
Nothing is trusted yet. Each image boots on throwaway test hosts and must pass real checks: failover, restore, and node drain.
If a check fails, the image is held. Nothing is shared, and running servers are untouched.
A passing image becomes the new current one, and is shared with production.
But passing tests is not proof that a live server can be replaced. So the factory rehearses the swap, while a test client keeps working, with a bad candidate on purpose.
A bad candidate rolls back before the old server stops.
Production is a separate gate. Only a rehearsed image can reach it, and a person approves the last step.
Old servers are stopped, not deleted, so going back is just a start.
What operations learn flows back into the next build.
Fix the image once. Build, prove, rehearse, and a person only approves the last step.
