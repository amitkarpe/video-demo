# Video framework decision — pentest explainer

Decision: benchmark **HyperFrames** first. This compares documentation and repository metadata, not five implemented prototypes. Evaluation 2026-11-07; maintenance means recent repository activity, not a support guarantee. All five repositories were unarchived when checked.

| Framework | Technical motion and HTML | Recording, audio, captions and offline MP4 | Longer training / effort | License and maintenance |
|---|---|---|---|---|
| [HyperFrames](https://github.com/heygen-com/hyperframes) | HTML/CSS and seekable timelines; familiar DOM, pan/zoom are authored animations. | Local renderer targets MP4; media and timed audio supported. SRT here is generated separately. | Chapters are composable; render time and authoring overhead on 20–30 min unmeasured. Moderate web/animation effort. | Apache-2.0; recent commits. |
| [Slidev](https://github.com/slidevjs/slidev) | Markdown/Vue presentation slides, web components; strongest for live slides, animation possible with web code. | Recordings/video export and narration synchronization require separate workflow; not benchmarked here. | Slides make chapters natural; MP4 editing adds effort. | MIT; recent commits. |
| [Revideo](https://github.com/midrender/revideo) | TypeScript-based programmatic video, animation and media; existing HTML layouts need adaptation. | Advertises video generation and rendering; caption/export workflow and offline Mac setup untested here. | Composable scenes, requires learning its APIs; long renders unmeasured. | MIT; recent activity in July 2026. |
| [Manim Community](https://github.com/ManimCommunity/manim) | Python mathematical/diagram animation; no native HTML layout reuse established. Camera movement possible through code. | Local animations to video; voice, footage and captions need integration; Mac setup not tested. | Excellent diagram control; integrating browser footage likely more work. | MIT; recent commits. |
| [aidemo](https://github.com/tandryukha/aidemo) | Storyboard-driven demo videos; its repository describes deterministic replay. HTML-based diagram animation/zoom capability not verified. | Advertises narrated captioned MP4 and no-key deterministic replay; Mac workflow not tested. | Screen demonstration potentially easy; abstract animated security diagrams require further assessment. | MIT; recent commits. |

**Go/no-go:** accept if the same 30–45-second scenario renders on the Mac to 1080p H.264/AAC with synchronized narration/captions, a purposeful diagram move, editable source, documented re-render and no paid services. A pass supports an initial choice, not proof of 20–30-minute throughput, voice quality, accessibility, or an enterprise deployment. If a material criterion fails, evaluate at most one fallback against the same script and assets. See `benchmarks/hyperframes/README.md` for observed results and limits.
